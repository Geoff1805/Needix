Comment fonctionne Needix ?

Une prise en main immédiate, fluide et pensée pour le quotidien de votre foyer.

1

1. Scan & Ajout instantané

Scannez vos codes-barres avec la caméra. Grâce à la base Open Food Facts et au cache local, le nom, la photo et les informations de l'article se remplissent automatiquement.

2

2. Suivi des stocks & Alertes

Définissez un stock minimal d'alerte et renseignez la date limite (DLC). L'application calcule les alertes visuelles par code couleur pour consommer en priorité.

3

3. Liste de courses automatique

Dès qu'un article passe sous son seuil minimal, il rejoint automatiquement la liste de courses, classée par magasin habituel pour faire vos courses en un temps record.

4

4. Sauvegarde & Export universel

Exportez et importez à volonté votre fichier JSON ou CSV standard. Compatible avec tous les tableurs (Excel, Calc) et partageable via votre cloud personnel (Nextcloud, Drive, etc.).

Foire Aux Questions

Tout ce que vous devez savoir sur la philosophie, l'hébergement Cloudflare et le modèle économique Needix.

Mes données d'inventaire sont-elles envoyées sur Cloudflare ou des serveurs distants ? ▾
Non, jamais. Bien que le site et l'application Web statique soient hébergés sur Cloudflare Pages pour une distribution rapide, vos données d'inventaire restent stockées 100% localement : dans la base de données interne de votre téléphone ou directement dans votre fichier JSON local sur votre ordinateur.
Quelle est la différence d'abonnement entre la version Web et l'application Mobile ? ▾
Seule la version Web (accessible dans votre navigateur via l'API HTML5 File System Access) est gratuite et sans abonnement. Les applications mobiles natives distribuées sur les stores proposent une période d'essai gratuit de 14 jours suivie d'un abonnement.
Puis-je mettre à jour mon stock avec un ticket de caisse numérique ? ▾
Oui ! Sur mobile comme sur la version Web, cliquez sur 'Ticket numérique', importez ou collez votre ticket de magasin : Needix détecte les produits et quantités achetés et vous propose d'actualiser votre inventaire en un clic.
Comment sauvegarder ou restaurer mon inventaire en cas de changement d'appareil ? ▾
Rendez-vous dans l'écran 'Export / Import' de l'application, cliquez sur 'Exporter mon inventaire en JSON' et enregistrez le fichier. Sur le nouvel appareil, cliquez simplement sur 'Restaurer depuis un fichier JSON' pour tout retrouver instantanément.
